# Character Sheet

**Best for:** the character bible of a series or client spot — the locked reference that stops faces, hair, and wardrobe from drifting between shots.

## Layout conventions
- One large portrait frame on the left (`store` fill, `rule` border), with a `sublabel` listing the exact prompt that produced it (the "anchor shot").
- Right side: three stacked columns or rows — **Look** (age, build, hair, skin), **Wardrobe** (top, bottom, shoes, accessories), **Voice & manner** (tone, catchphrases, walk).
- Each attribute is `muted` label + `ink` value on the same line. Keep values copy-pasteable; the sheet doubles as a prompt block.
- A "Do not change" strip at the bottom (`focal` border, thin) listing the 3–4 locked elements.
- The sheet is meant to be screenshotted into every subsequent prompt, so keep it tight: one screen, no scrolling.

## Anti-patterns
- Reference images that are clearly different characters. If two images don't match, the sheet is broken; say so.
- Attributes so vague they can't be checked ("expressive face"). Every attribute must be falsifiable.
- Decorating the frame with gradients or drop shadows. It's a reference doc, not a poster.
